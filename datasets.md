# Dataset Sources (20 Datasets Used in Benchmarking)

Below are the datasets used in this project, along with their classification task and public source links.

| Dataset Name | Classification Task | Source Link |
|--------------|---------------------|-------------|
| Loan_data | Loan eligibility prediction | https://www.kaggle.com/datasets/burak3ergun/loan-data-set |
| Liver_patient | Liver disease prediction | https://archive.ics.uci.edu/dataset/225/ilpd+indian+liver+patient+dataset |
| Stroke | Brain stroke prediction |  https://www.kaggle.com/datasets/shashwatwork/cerebral-stroke-predictionimbalaced-dataset |
| Diabetes | Diabetes prediction |  https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database |
| Heart_attack | Heart attack prediction | https://www.kaggle.com/datasets/rashikrahmanpritom/heart-attack-analysis-prediction-dataset |
| Breast_cancer | Breast cancer (Wisconsin) prediction |  https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic |
| Wine_quality | Wine quality classification |  https://archive.ics.uci.edu/dataset/186/wine+quality |
| default | Credit card default / student default classification | https://rdrr.io/cran/ISLR/man/Default.html |
| diabetes2 | Diabetes classification (early stage) |  https://www.kaggle.com/datasets/andrewmvd/early-diabetes-classification |
| Heart_failure | Heart failure clinical record based prediction | https://archive.ics.uci.edu/dataset/519/heart+failure+clinical+records |
| Student_data | Student dropout / academic success classification |  https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success |
| Cell_samples | Cell sample binary classification |  https://github.com/kvinlazy/Dataset/blob/master/cell_samples.csv?plain=1 |
| New_model | Chronic kidney disease classification |  https://www.kaggle.com/datasets/abhia1999/chronic-kidney-disease |
| Metabolic_syndrome | Metabolic syndrome presence prediction | https://www.kaggle.com/datasets/antimoni/metabolic-syndrome |
| gbsg | Breast cancer recurrence (Royston & Altman) |  https://www.kaggle.com/datasets/utkarshx27/breast-cancer-dataset-used-royston-and-altman |
| drug200 | Drug type classification | https://github.com/kvinlazy/Dataset/blob/master/drug200.csv |
| babies | Birth weight / smoker vs non-smoker classification |  https://www.kaggle.com/datasets/debjeetdas/babies-birth-weight |
| Disease_symptoms_and_patient | Diagnosis classification | https://www.kaggle.com/datasets/uom190346a/disease-symptoms-and-patient-profile-dataset |
| Rice_classification | Rice grain type classification |  https://www.kaggle.com/datasets/mssmartypants/rice-type-classification |
| heart | Heart disease prediction |  https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset |
